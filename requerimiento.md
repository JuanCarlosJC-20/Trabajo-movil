## Temas a desarrollar

```
1.Uso de botones.
2.Dialog o Modal.
3.Dropdown compatible con Android e iOS.
4.Calculadora básica.
5.Scroll Loading.
6.Navegación:
```
- Stack Navigation.
- Bottom Menu.
- React Navigation.
- Drawer Layout.

Nota: todos los elementos deben ser compatibles con IOS y android y su funcionalidad.

# Descripción de la actividad

El aprendiz deberá construir una aplicación móvil funcional en React Native implementando
componentes básicos y avanzando progresivamente hasta integrar navegación y funcionalidades
dinámicas.

# Requerimientos técnicos

## Herramientas sugeridas

- Node.js
- React Native
- Expo CLI
- Visual Studio Code

# Actividades a desarrollar

# Parte 1 – Uso de Botones (Nivel Básico)

## Instrucciones

```
1.Crear una pantalla principal.
2.Agregar mínimo 3 botones.
3.Implementar eventos onPress.
4.Aplicar estilos personalizados.
```

## Evidenciar

- Interacción funcional.
- Cambio de texto o mensajes.

# Parte 2 – Dialog o Modal (Nivel Básico)

## Instrucciones

```
1.Implementar un Dialog o Modal.
2.Mostrar mensajes informativos.
3.Abrir y cerrar el modal mediante botones.
```
## Evidenciar

- Apertura correcta.
- Cierre correcto.
- Diseño visual funcional.

# Parte 3 – Dropdown compatible Android/iOS

# (Nivel Básico – Intermedio)

## Instrucciones

```
1.Implementar un Dropdown o Picker.
2.Mostrar diferentes opciones.
3.Visualizar el valor seleccionado.
4.Validar funcionamiento en Android e iOS.
```
## Evidenciar

- Selección funcional.
- Compatibilidad multiplataforma.

# Parte 4 – Calculadora Básica (Nivel

# Intermedio)

## Instrucciones

```
1.Crear una interfaz de calculadora.
2.Implementar:
```

- Resta.


- Multiplicación.
- División.
3.Mostrar resultados dinámicamente.

## Evidenciar

- Operaciones funcionales.
- Actualización correcta del resultado.
- Validación básica de datos.

# Parte 5 – Scroll Loading (Nivel Intermedio)

## Instrucciones

```
1.Crear una lista de elementos.
2.Implementar:
```
- ScrollView o FlatList.
3.Mostrar indicador de carga (ActivityIndicator).

## Evidenciar

- Desplazamiento vertical funcional.
- Indicador de carga visible.
